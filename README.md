# toys-reporting

Статус проектов хранится в `config/project-status.json`.

- Массовые обновления и полный regression-прогон выполняются только для `active`.
- `inactive` — архивные проекты: ссылки и история сохраняются, но в массовые релизы они не входят.
- После каждого массового релиза в отчёте нужно перечислять конкретные обновлённые страницы.
