# TOYS Agency Platform

Новый Cloudflare-фундамент для переноса дашбордов и CRM с Google Sheets и GitHub Pages.

## Статус

Этап 1 подготовлен изолированно. Действующие дашборды, таблицы и Apps Script не переключены и продолжают работать как раньше.

Готово:

- схема единой многоклиентской базы D1;
- 15 активных проектов заведены как `draft`;
- рекламные метрики, лиды, история статусов, комментарии, продажи и недельные итоги;
- журнал синхронизаций и аудит изменений;
- публичный health-check без клиентских данных;
- закрытый внутренний API с отдельным серверным токеном;
- ежедневный Cron-каркас;
- автономные тесты миграций и API.

## Локальная проверка без Cloudflare-аккаунта

```powershell
node --check src/index.js
node --test tests/*.test.mjs
```

## Что потребуется для первого Cloudflare-деплоя

1. Создать корпоративный Cloudflare-аккаунт.
2. Подключить домен `toys-agency.com` или предоставить доступ к существующей зоне.
3. Включить Workers Paid ($5/месяц) перед production-запуском.
4. Создать D1 базу командой `wrangler d1 create toys-agency`.
5. Заменить нулевой `database_id` в `wrangler.jsonc` на выданный Cloudflare ID.
6. Сохранить `TOYS_INTERNAL_TOKEN` через `wrangler secret put`, не в GitHub.
7. Применить миграции и развернуть Worker.

До этих действий проект можно полностью проверять локально бесплатно.
