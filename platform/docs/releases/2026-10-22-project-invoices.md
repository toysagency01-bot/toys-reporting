# Project documentation and desktop invoices — 2026-10-22

Each project in the master cabinet now has a Documentation entry. Its invoices
are reachable from the sidebar project selector, project table and project action
panel. Direct project links use `/master/#documents?project=SLUG`. No documentation
entry is exposed in client dashboards. The user explicitly limited this release
to desktop to shorten delivery; mobile navigation hides the new entry.

The editor includes a live paper preview, sender/customer/payment details,
English/Russian PDF labels, invoice/due dates, currency, up to 40 service lines,
discount and VAT. Saving requisites creates project-scoped defaults for new
invoices; existing invoices retain their own data snapshots. Duplication creates
an independent draft, new sequential number and current Tbilisi invoice date,
retaining the original payment-term duration. Custom numbers remain unique within
the project and advance automatic numbering safely.

Amounts are calculated in integer minor units, with decimal quantities and
explicit rounding per service line, discount and tax. Issued/paid/cancelled
invoices and PDF generation require complete parties and positive priced lines.
Drafts may be incomplete. Draft deletion is soft; numbers are not recycled.
Concurrent edits use version guards, and writes/duplication are idempotent.
Navigation warns about unsaved edits; accepted discards clear the editor state.

PDFs are generated by the Worker directly from saved invoice data, using pdf-lib
and embedded Apache-licensed Open Sans. Cyrillic, Czech text and multipage wrapping
are supported. PDFs download as files rather than requiring the browser print
workflow. No R2, external invoice service, external font request or new credential
is required. Download from an unsaved editor saves the current version first.

All document, default and PDF routes require master access plus current project
assignment. Administrators access all projects; employees access assigned
projects; clients are denied, including direct API URLs. Origin checks and request
size limits apply to writes. The administrator change journal records invoice
numbers, actors, versions and status/amount changes without exposing bank details.
