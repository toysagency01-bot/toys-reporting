# TOYS WIKI in the master cabinet

The complete reviewed WIKI is available at `/master/#wiki`. Administrators and
team members, including teammates without project assignments, can read its
63 hierarchical sections. Clients and anonymous visitors cannot read or search
the content. Text is stored in private D1 tables, not in public/static bundles.

Administrators now edit the article title and formatted text directly in place.
There is no edit mode or Save button. Text selection exposes formatting tools;
changes save after a short pause, on blur and before internal navigation.
The interface displays pending, saving, saved and failure states.

Each article has one ordered write stream. Typing during a save remains a newer
draft and is saved with the acknowledged version. Lost acknowledgements are
reconciled by exact readback. A concurrent administrator's change blocks writes
instead of overwriting their text. Failed drafts remain in memory, can be
downloaded, and block navigation until saved or explicitly discarded. Closing
the browser warns about unsaved work. Private drafts are not persisted in
browser storage. Restoring a historical version creates a new revision.

The Markdown renderer makes empty exported attachment links visible. A custom
paragraph serializer preserves literal numbered/hyphen prefixes. Opening an
article never writes or reformats its stored content. The HTML shell injects
bundled code through replacement functions so JavaScript replacement tokens in
editor dependencies cannot alter the document.
